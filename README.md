# Circe's Circular Minimap - Region & Clock

A smooth circular minimap with region names and a 12-hour in-game clock. Press F3 to show or hide it.

Created for **MissViciousCirce** with code generated and refined using OpenAI Codex. The internal mod folder remains `CirceHUD` for update compatibility.

**0.1.4-alpha - toggle recovery fix; automated checks pass, in-game validation pending. Publication is on hold.**

## What it does

- Renders a live, perspective overhead view of nearby loaded game geometry.
- Uses a GPU-rounded circular brush with a thin cyan outline and transparent corners.
- Displays a generated player pointer, a region label and an AM/PM clock.
- Reads time from the game's day/night component, including while standing still.
- Captures terrain every 750 ms; animates the pointer separately every 33 ms with shortest-path smoothing.
- Applies optional dark-water grading only to the map camera, keeping the cyan outline and labels bright.
- Uses its own local camera and capture settings. It does not move the player, edit game time or change the main camera's rendering flags.

This is a **local overhead view**, not a pre-drawn world atlas. Unloaded areas cannot be displayed. Buildings and cave ceilings may obscure lower geometry, and appearance can vary by location. The larger view enlarges the local map; it is not an independently surveyed full-world map.

## Independence

Circe HUD contains original Lua code and generated pointer artwork. It does not bundle another minimap's source or a pre-made world map image.

The pointer is generated by `tools/build_assets.py`. Map pixels are rendered at runtime by the user's installed game; no terrain images, game binaries or extracted game assets are distributed. UE4SS and Subnautica 2 remain external requirements with their own licenses. The MIT license here covers this repository's original code and artwork only.

## Requirements and installation

- Subnautica 2 for Windows.
- A compatible UE4SS installation with its standard `UEHelpers` module and `LoopInGameThreadWithDelay` support.

Simple Minimap is **not required**. Disable another minimap before enabling Circe HUD, as both may occupy the same location and use the same keys.

For Vortex or a normal manual installation, use `Circes-Circular-Minimap-Region-and-Clock-0.1.4-alpha.zip`. It contains only the `CirceHUD` runtime folder, README and license. See [installation instructions](NEXUS-README.txt). Archive routing is checked against the installed Subnautica 2 Vortex extension 1.5.1; full live Vortex lifecycle testing remains pending.

The separate `CirceHUD-0.1.4-alpha.zip` is a development package with source, tests and a personal migration installer. To use that installer, save and close the game, extract the development package, open PowerShell in the extracted folder and run:

```powershell
.\Install.ps1 -GamePath 'D:\SteamLibrary\steamapps\common\Subnautica2'
```

Replace the example with your Steam game folder. The installer backs up any overwritten Circe HUD files, records previous enablement, disables the old Simple Minimap in UE4SS, and enables Circe HUD. It does not delete the old mod, its artwork, its settings, or exploration data. The installer prints a backup folder. `-WhatIf` previews the change.

Vortex can redeploy enablement files later. Keep the old minimap disabled in Vortex if you continue using Circe HUD. For a manual installation, copy `CirceHUD` into `Subnautica2/Binaries/Win64/ue4ss/Mods`, then enable it with `enabled.txt` or a `CirceHUD : 1` entry in `mods.txt`.

## Controls and settings

| Action | Key |
| --- | --- |
| Hide/show HUD | F3 |
| Enlarge/restore local map | M |
| Zoom in/out | Numpad + / - |

Edit `CirceHUD/Scripts/settings.lua` while the game is closed. Defaults are a 280-unit top-left circle, a 300-metre view width, a 512-pixel render target, a 750-ms terrain refresh interval, and a separate 33-ms arrow interval. Increasing range does not load distant terrain. Increasing resolution or refresh frequency increases GPU work.

`DarkWater = true` enables a higher-contrast black/navy palette using final-color capture and local post-process overrides. `MapContrast` adjusts the contrast. Exposure is fixed for the capture; the player camera is untouched. Set `DarkWater = false` to restore the lighter scene-color appearance (`CaptureSource = 3`). If the grade properties are unavailable, the code retains the original capture source and logs the reason.

`ArrowRefreshMs = 33` targets about 30 updates per second. `ArrowSmoothing = 0.55` blends toward the latest camera heading; `1` removes smoothing. Arrow updates do not recapture terrain or re-query region/time, and pause while the HUD is hidden.

Regions may read **Unknown region** above water because the game does not supply a zone tag there. Missing time data displays **--:--**. North is the game's -Y direction. The overhead camera is oriented with north at the top, and the pointer converts the player camera yaw to a compass bearing (yaw + 90 degrees). Camera heading is preferred to pawn-body rotation. Direction alignment has been confirmed in-game.

## Testing and status

Native function names and relevant parameter signatures were checked against the installed game. Automated checks cover Lua syntax, clock boundaries, region formatting, option validation and camera positioning. Engine calls are tested with mocks; those do not prove correct rendering inside Unreal.

Version 0.1.3's visuals were confirmed in-game, but repeated F3 toggles subsequently caused the HUD to stop returning. The log recorded a UE4SS wrapper error followed by an EngineTick callback exception and hook removal. The same session's Mod Settings control queue stopped draining; Quick Stack also stopped responding. These symptoms require a full game restart before retesting.

Version 0.1.4 replaces the two asynchronous scheduling chains and per-key game-thread dispatch with one persistent game-thread timer. Key callbacks only enqueue plain Lua commands, which that timer applies in order. Stale wrapper validation and cleanup are protected so a recoverable widget error cannot terminate updates. Fourteen automated tests cover the original clock, compass and rendering calculations plus 50 hide/show cycles, rapid ordered key bursts, hidden map transitions, and recovery after both widget validation and disposal throw. These tests use mocks; they do not reproduce UE4SS's native threading behavior or replace live validation. Repeated F3 toggles, the Mod Settings controls and Quick Stack N still need a fresh-session check before publication.

This remains an alpha release. Live Vortex install/update/uninstall testing and broader hardware/game-build testing are pending. Runtime diagnostics start with `[CirceHUD]` in `ue4ss/UE4SS.log`. No analytics or network requests are made by this mod.

Run development checks with Python, `lupa` and Pillow installed:

```text
python tools/build_assets.py
python tests/test_model.py
```

## Undo the switch

Close the game. Remove `CirceHUD/enabled.txt`, set `CirceHUD : 0` in `ue4ss/Mods/mods.txt`, then re-enable your previous minimap through Vortex or its original enablement files. Previous `mods.txt` and Simple Minimap marker information are saved in the install backup; avoid restoring a whole old `mods.txt` over unrelated later changes.
